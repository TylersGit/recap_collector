# Recap Collector (WIP)

A Python based tool  for checking whether a sports game has finished.  
If the game finished, it will check for a recap video, and send it to you. 

Designed for abroad fans of American Sports.

---

Originally designed for collecting recaps for fantasy baseball, this tool is currently going under generalization, to support getting recaps for multiple sports and teams.
